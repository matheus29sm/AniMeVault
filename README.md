# AniMeVault

AniMeVault is a personal project inspired by platforms like MyAnimeList,
created to organize and manage media works such as **anime, manga, manhua, and webtoon**
in a personalized digital vault.


## 🛠️ Planned Features

- **Ranking System**: Works will be organized in a positional ranking list.

    - Example:
        - Rank `1` → Favorite
        - Rank `100` → Least Liked

    - Rankings will be editable, allowing users to reorder their collection as preferences evolve.
